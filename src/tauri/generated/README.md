# Generated IPC types

The `.ts` files in this folder are generated by [ts-rs](https://github.com/Aleph-Alpha/ts-rs)
from the Rust structs and enums that cross the IPC boundary. Do not edit
them by hand - change the Rust definition and regenerate:

```sh
pnpm types:generate
```

(from the repository root; that script runs
`cargo test --manifest-path src-tauri/Cargo.toml --lib export_bindings`,
which is how ts-rs emits these files). CI fails when a committed file
disagrees with the Rust definitions, so a stale type cannot ship.
